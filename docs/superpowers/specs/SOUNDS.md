# Closed Hat

- Wave: White noise
- HPF
  - 5–8 kHz for a bright closed hat
  - 3–5 kHz for a softer hat
- Envelope:
  - Attack: 0 ms
  - Decay: 20–80 ms
  - Sustain: 0
  - Release: 5–20 ms

# Open Hat

Same as Closed Hat but:

- Envelope:
  - Attack: 0
  - Decay: 300–900 ms
  - Release: 100–400 ms
